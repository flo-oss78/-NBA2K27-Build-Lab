# Player Reference Data

`players-core.js` contains a small verified NBA 2K27 reference set used by the V15 similarity engine.

Source: 2KRatings player pages. Checked 2026-09-12.

Profiles currently included:
- Stephen Curry
- Luka Doncic
- Shai Gilgeous-Alexander
- Anthony Edwards
- Jayson Tatum

Axis mapping follows the research design:
- Finition ← Inside Scoring
- Tir ← Outside Scoring
- Organisation ← Playmaking
- Défense ← Defense
- Physique ← Athleticism

This mapping is a product normalization layer; it does not alter the source values.
